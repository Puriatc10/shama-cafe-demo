# شاما — وب‌سایت دمو

دموی قابل ارائه برای «کافه رستوران شاما» (تهران).

- استاتیک، بدون build step
- منو از منوی عمومی رستوران گرفته شده (۱۱ دسته، ۷۱ آیتم)
- RTL فارسی، تم مشکی-طلایی

## اجرا
```bash
python -m http.server 4321
```
سپس `http://127.0.0.1:4321`

## ساختار
- `index.html` — صفحه اصلی
- `css/` — tokens، base، و استایل هر بخش
- `js/` — data (منو)، store (سبد/قیمت‌گذاری)، و ماژول هر بخش
- `assets/` — تصاویر منو و فونت‌ها
